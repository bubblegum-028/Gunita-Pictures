# Gunita Pictures — Remy-inspired portfolio

A black, minimalist, editorial photography/film portfolio inspired by the interaction patterns and visual direction of the provided Remy Shoots reference. It is an original Gunita Pictures implementation, not a copy of the source site's code or assets.

## Included
- Full-screen hero / intro
- Works section for Weddings, Kiddie, Corporate, Gender Reveal
- Still gallery with category filters
- Responsive masonry-style gallery
- Fullscreen lightbox with keyboard navigation
- Motion/video section
- Services section
- Booking email CTA
- Mobile responsive layout
